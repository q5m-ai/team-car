# Agent instructions

Read README.md and the relevant docs before changing product scope or architecture.

- Preserve the voice-first, low-distraction professional team-car experience.
- Distinguish verified integration capabilities from design hypotheses.
- Never invent race state, teammate intent, or power-up inventory.
- Keep freshness, event detection, prioritization, and advice expiry testable independently of a language model.
- Use synthetic/sanitized fixtures; never commit credentials, raw audio, or personal race data.
- Do not access undocumented game interfaces without evaluating permission and applicable terms.
- No automated game control. Public hosting, deployment, and shared infrastructure provisioning require explicit authorization.
- Make focused changes and document how they were validated. Do not claim tests ran when no runnable implementation exists.
